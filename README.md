# YourCoffee – Business Website

## About This Project
YourCoffee is a modern, fully responsive coffee business website designed to showcase premium coffee products and provide an engaging user experience.  
The website includes the following sections:

- **Home** – Hero section with transform animations and call-to-action buttons  
- **Menu** – Interactive coffee product slider  
- **About** – Founder story, brand journey, and process videos  
- **Testimonials** – Auto-scrolling animated reviews  
- **Contact** – Contact form with JavaScript validation and popup success message  

---

## Features
- Responsive navigation bar with mobile dropdown  
- Interactive menu slider  
- Transform-based hero animation  
- Smooth testimonial auto-scroll animation  
- Embedded videos for visual storytelling  
- JavaScript-powered form validation  
- Pixel-perfect responsive layout across devices

## Challenges & Solutions

### **1. Responsiveness**
Ensured seamless layout scaling using media queries, grid, and transform overrides.

### **2. Menu Slider Interaction**
Implemented custom slider logic with arrow navigation and smooth transforms.

### **3. Dropdown Menu Behavior**
Handled open/close behavior using event listeners to prevent layout breaking on small screens.
